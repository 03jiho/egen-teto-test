# 에겐테토 테스트

밥 먹는 습관부터 컴퓨터 끄는 법까지, 10가지 질문으로 알아보는 완전 비과학적 에겐테토 유형 테스트입니다. 순수 예능용 콘텐츠이며 학술적 근거는 전혀 없습니다.

## 실행 방법

빌드나 의존성 설치 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

```bash
open index.html   # macOS
start index.html  # Windows
```

정적 파일이라 GitHub Pages, Netlify, Vercel 등 아무 정적 호스팅에 그대로 올려도 동작합니다.

## 결과 유형

야만인 → 네안데르탈인 → 테토형 → 밸런스형 → 에겐형 순으로 판정되며, 특정 조합을 만족하면 숨겨진 보너스 결과(오스트랄로피테쿠스, 찡찡보스)가 등장합니다.

## 결과 공유

결과 화면의 "결과 공유하기"를 누르면 답변이 URL 쿼리 파라미터(`?a=...`)로 인코딩된 링크가 생성됩니다. 그 링크로 접속하면 퀴즈를 다시 풀지 않고 바로 해당 결과 화면이 표시됩니다.
