# 에겐테토 테스트

밥 먹는 습관부터 컴퓨터 끄는 법까지, 10가지 질문으로 알아보는 완전 비과학적 에겐테토 유형 테스트입니다. 순수 예능용 콘텐츠이며 학술적 근거는 전혀 없습니다.

## 배포 링크

https://03jiho.github.io/egen-teto-test/

## 실행 방법

빌드나 의존성 설치 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

```bash
open index.html   # macOS
start index.html  # Windows
```

정적 파일이라 GitHub Pages, Netlify, Vercel 등 아무 정적 호스팅에 그대로 올려도 동작합니다.

## 결과 유형

기본 결과는 테토형 → 밸런스형 → 에겐형 세 가지입니다. 전 문항을 야만인 선택지로만 고르면 숨겨진 결과 "오스트랄로피테쿠스"가, 전 문항을 에겐 선택지로만 고르면 숨겨진 결과 "찡찡거리는 예민보스"가 등장합니다. (단, 결과 화면 자체에는 스포일러 방지를 위해 힌트만 "히든 결과 등장"으로 표시되고 실제 이름은 달성해야 보입니다.)

## 공유 기능

- **테스트 공유하기** (상단 마스트헤드): 퀴즈 자체의 링크를 공유합니다.
- **결과 공유하기** (결과 화면): 답변을 URL 쿼리 파라미터(`?a=...`)로 인코딩한 링크를 공유합니다. 이 링크로 접속하면 퀴즈를 다시 풀지 않고 바로 해당 결과 화면이 표시됩니다.

두 버튼 모두 지원 브라우저에서는 공유 시트(Web Share API)를, 지원하지 않으면 클립보드 복사를 사용합니다.
